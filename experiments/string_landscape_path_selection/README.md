# MAAT String Selection II — Structural Path Selection

This experiment extends the existing string-landscape vacuum-ranking benchmark
into a structural path-selection benchmark.

## Status

This is a phenomenological transition-graph benchmark. It is not a
Coleman-De Luccia tunnelling calculation, not a microscopic string decay-rate
derivation, and not a complete landscape dynamics model.

## Source Data

The benchmark uses the existing reduced IIB/KKLT bridge output:

```text
../string_landscape_selection/structural_selection_iib_kklt_bridge_results.json
```

Only candidates classified as minima are used as graph nodes.

## Core Idea

Paper I ranked candidate vacua as endpoints:

```text
B_i -> F_MAAT[B_i]
```

Paper II assigns transition weights to graph edges:

```text
B_i -> B_j
```

with a phenomenological path action:

```text
A_ij =
  barrier_ij
  + lambda_F max(F_j - F_i, 0)
  + lambda_control control_ij
  + lambda_tadpole tadpole_ij
  + lambda_stability stability_loss_ij
```

and transition probability:

```text
P_ij ∝ Gamma_ij exp[-A_ij]
```

where `Gamma_ij = exp[-barrier_ij]` is a reduced barrier proxy.

## Interpretation

The static energy-best minimum is not the static structural-best minimum.
The structural transition graph identifies a two-edge path from the
energy-best node to the structural-best node, while the top transition edges
selected by structural action have no overlap with the top edges selected by
energy action alone.

This supports the main claim:

```text
MAAT extends static vacuum ranking to structural landscape flow.
```
