# SAT Structural Hardness IIb — Paper 50b

This folder contains the reproducibility bundle for the Paper 50 companion
test:

```text
SAT Structural Hardness IIb:
Local Frustration Fields and the Failure of Scalar Compression
```

## Status

This is a companion experiment to Paper 50, not a new universality claim and
not the Paper 51 roadmap item announced in Paper 49. It tests one focused
thesis:

```text
Global MAAT scalar compression is too lossy for SAT hardness.
SAT hardness is better captured by local frustration fields, rare-event tails,
and hotspot geometry.
```

The target remains a deterministic DPLL node-count proxy. The experiment is
therefore not solver-independent in the strong sense and is not a modern CDCL
benchmark.

## Test Design

The script generates a fixed-seed synthetic ensemble with three formula
families:

- random 3-SAT,
- planted 3-SAT,
- modular/community-like 3-SAT.

It compares the compression ladder:

```text
raw local fields
-> support scores H,B,S,V
-> R_resp, R_rob
-> scalar F_MAAT
```

against local frustration summaries:

```text
frust_q95
frust_q99
tail mass
hotspot cluster fraction
R_tail
R_var
R_cluster
R_sat
```

## Reproduce

Run from this folder:

```bash
python3 sat_frustration_fields_paper50b.py
```

## Interpretation

The thesis is supported in a restricted sense. Scalar `F_MAAT` and global
robustness remain weak, while local frustration fields become useful once the
phase-density and formula-family channels are retained.

This does not show that MAAT solves SAT hardness. It shows something more
specific and more useful:

```text
SAT hardness is damaged by aggressive global scalar compression.
The useful signal lives in graph-local, multi-scale frustration geometry.
```

The Paper-50c extension adds an explicit `F_MAAT_multi` test. The result is
important but non-triumphal: the single re-compressed scalar is weak, while its
components become useful once density and formula-family context are retained.
This supports the defect-field interpretation rather than a new one-number
hardness score.
