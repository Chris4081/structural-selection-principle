# Paper 57 Experiment — SAT Defect-Field Projection Decomposition

**Where Does SAT Hardness Live?**  
*Mean, Tail, Cluster, and Scale Projections of Defect-Field Geometry*

This experiment is a downstream ablation of Paper 55 and an empirical test of
the operator language defined in Paper 56. It asks whether CDCL hardness signal
in canonical SAT families is carried primarily by:

- mean defect summaries,
- tail / high-quantile defect structure,
- connected hotspot clusters,
- scale / propagation / conditioning terms,
- or ordinary graph baselines.

The script does not regenerate SAT instances and does not rerun solvers. It
reads the Paper-55 table:

```text
experiments/sat_cdcl_external_paper55/outputs_paper55/paper55_sat_cdcl_instances.csv
```

## Run

From this directory:

```bash
python3 sat_projection_decomposition_paper57.py
```

From the repository root:

```bash
python3 experiments/sat_projection_decomposition_paper57/sat_projection_decomposition_paper57.py
```

If the Paper-55 CSV is stored elsewhere, set:

```bash
PAPER55_CSV=/path/to/paper55_sat_cdcl_instances.csv python3 sat_projection_decomposition_paper57.py
```

## Core Result

Within-family cross-validation remains modest. The best random-forest model is
the standard graph baseline (`R2 = 0.2169`, Spearman `0.4234`). The full
defect-projection model is close but lower (`R2 = 0.1996`, Spearman `0.3751`).

Inside the all-defect projection model, grouped permutation importance shows:

| Projection | R2 drop |
|------------|--------:|
| tail | `0.4044` |
| scale | `0.3414` |
| mean | `0.1567` |
| cluster | `0.0229` |

The strict leave-family-out test remains weak. Tail projections give the best
overall LFO Spearman (`0.1607`) but still negative LFO `R2`, so the result is a
localisation of signal rather than a general transfer success.

## Scientific Status

This is not a proof that SAT hardness is solved by structural selection. It is
a projection-decomposition benchmark. The main finding is that scalar
compression is not the whole story: tail and scale structure carry the
strongest defect-field signal, but family transfer remains unresolved.
