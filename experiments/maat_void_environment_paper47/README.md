# Paper 47 — From Environmental Screening to Observable Void Signatures

This experiment extends Paper 46 from an internal environmental-screening
benchmark to an observable halo/void-environment signature.

## Status

This is a phenomenological bridge benchmark. It is not a full halo model, not
a weak-lensing likelihood, not a Boltzmann-code calculation, and not a
microscopic derivation of chameleon, Vainshtein, symmetron, or other screening
mechanisms.

## Core Idea

Paper 46 used an effective environmental kernel:

```text
C_env(z, Delta, Sigma_env) = C_hat_proj(z) * S_env(Delta, Sigma_env)
```

Paper 47 gives `Sigma_env` a halo-environment interpretation through a bounded
tidal/shear proxy:

```text
Sigma_env(q) = q^2 / (q^2 + q_star^2)
```

with the screened kernel:

```text
S_env(Delta, q)
  = [1 + alpha_rho Delta_+^n + alpha_sigma Sigma_env(q)^m]^(-1)

Delta_+ = max(Delta - 1, 0)
```

The metric response channels are inherited from Paper 45:

```text
mu_env(z)        = 1 + eta_g  C_env(z)
eta_slip_env(z) = 1 + beta_s C_env(z)
Sigma_lens_env  = mu_env(z) * [1 + eta_slip_env(z)] / 2
```

The new observable diagnostic is the lensing-to-growth response ratio:

```text
R_LG(z) = Sigma_lens_env(z) / mu_env(z)
        = [1 + eta_slip_env(z)] / 2
```

## Interpretation

The benchmark predicts that residual MAAT metric response should be largest in
void-like environments, suppressed in clusters, and essentially absent in
high-density local-test proxies. The concrete target signature is a
void-versus-cluster lensing/growth contrast:

```text
Delta R_LG^(void-cluster) ~= 1.26 percentage points
```
