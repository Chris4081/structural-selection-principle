# Quantum Pointer-State Selection — Paper 51

This folder contains the reproducibility bundle for Paper 51:

```text
Quantum Pointer-State Selection:
A MAAT v1.4 Defect-Field Benchmark in a Non-Commuting Lindblad System
```

## Status

This is a toy quantum benchmark, not a full theory of decoherence, not an
experimental fit, and not a derivation of pointer states from first principles.
It tests whether MAAT v1.4 field features retain pointer-robustness information
that is lost by scalar compression or simple rate-only baselines.

## Model

The benchmark uses a single qubit with:

- Hamiltonian generator `H = hz sigma_z + hx sigma_x`,
- z-dephasing Lindblad channel,
- x-dephasing Lindblad channel,
- amplitude-damping channel.

The target is:

```text
fidelity(initial pure state, evolved state)
```

after Lindblad evolution. All features are computed from the initial state and
generator parameters, not from the final evolved state.

## Reproduce

Run from this folder:

```bash
python3 quantum_pointer_state_selection_paper51.py
```

## First Run Results

Fixed seed: `51053`

| Model | CV `R2` |
| --- | ---: |
| MAAT scalar/supports | `0.5383 ± 0.0151` |
| MAAT v1.4 field features | `0.7424 ± 0.0057` |
| Rates only | `0.0542 ± 0.0547` |
| Basis geometry only | `-0.1134 ± 0.0331` |
| Hamiltonian only | `-0.0406 ± 0.0241` |
| Domain combo | `0.1362 ± 0.0291` |

Key deltas:

| Comparison | Delta `R2` |
| --- | ---: |
| v1.4 field minus scalar MAAT | `+0.2041` |
| v1.4 field minus domain combo | `+0.6062` |

## Interpretation

The benchmark supports the v1.4 defect-field thesis in a second domain:

```text
Pointer-state robustness is not captured by rates alone.
Scalar MAAT retains moderate signal.
MAAT v1.4 field features retain substantially more signal.
```

The result remains a toy-model result. The field features are operational
diagnostics, not microscopic quantum postulates.
