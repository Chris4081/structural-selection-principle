# SAT Structural Hardness II — Paper 50

This folder contains the reproducibility bundle for Paper 50:

```text
SAT Structural Hardness II:
Graph-Local Defects, Backdoor Density, and Solver-Independent Structural Hardness
```

## Status

This is a synthetic random-3-SAT benchmark designed to address the SAT
weakness identified in Paper 49. It is not a proof of `P != NP`, not a solver
competition, and not a claim that the current MAAT defect basis fully solves
SAT hardness.

## Core Idea

The older SAT validation used coarse global fields and performed poorly.
Paper 50 tests a richer feature map:

- constraint-graph expansion,
- clause-variable interaction cycles,
- backdoor-density proxy,
- local covariance conditioning,
- unit-propagation depth,
- contradiction rate,
- v1.2.1-style emergent robustness.

The target is a bounded DPLL node-count proxy:

```text
log_nodes = log(1 + DPLL_nodes)
```

The main comparison is:

```text
MAAT graph-local defects
vs density-only
vs standard graph baseline
vs stability-only
vs scalar F_MAAT
vs shuffled-null defects
```

## Reproduce

Run from this folder:

```bash
python3 sat_structural_hardness_paper50.py
```

## Interpretation

This is a partial success and a useful failure. Graph-local MAAT diagnostics
clearly beat shuffled-null structure and improve over density-only once the SAT
phase-density channel is retained. However, the ordinary standard graph
baseline remains slightly stronger in this synthetic benchmark.

The result narrows the SAT problem: SAT hardness is graph-local and
phase-aware. It is not captured by scalar `F_MAAT` or stability alone.
