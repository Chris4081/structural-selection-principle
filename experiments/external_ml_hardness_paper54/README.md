# Paper 54 — External ML Sample-Hardness Benchmark

**External Validation of Structural Modes**  
*MAAT Defect Features on Public Datasets Accessed via scikit-learn*

This experiment is the first deliberately external benchmark after the
repository-internal transfer tests in Papers 52--53.

The goal is not to prove universality.  The goal is to test whether simple
MAAT-style structural supports retain sample-hardness information on public
datasets whose targets were not generated by the MAAT framework.

## External Datasets

The script accesses public datasets through `scikit-learn`:

| Dataset | Samples | Features | Classes |
|---|---:|---:|---:|
| `breast_cancer` | 569 | 30 | 2 |
| `wine` | 178 | 13 | 3 |
| `digits` | 1797 | 64 | 10 |

## Predeclared Hardness Target

Sample hardness is defined by repeated stratified 5-fold cross-validation
using a fixed Random Forest classifier.

Primary target:

```text
hardness_i = fraction of CV repeats in which sample i is misclassified
```

Secondary diagnostic:

```text
hybrid_hardness = 0.70 * error_rate
                + 0.20 * boundary_entropy
                + 0.10 * confidence_loss
```

The hybrid target is reported only as a stability diagnostic because the small
public datasets can be nearly solved by the classifier.

## MAAT Supports

The supports are computed only from feature-space geometry and labels:

| Support | Operational definition |
|---|---|
| `H` | local kNN label coherence |
| `B` | local class-margin dominance |
| `S` | controlled local-spread activity window |
| `V` | local kNN density / connectivity |
| `R_rob` | v1.2.1 robustness closure |

The v1.4 field feature set adds defect statistics, local defect-neighbourhood
statistics, tail ranks, and hotspot-neighbour fractions.

## Baselines

The benchmark compares MAAT features against:

- external geometry features,
- label-geometry features,
- combined geometry,
- scalar predeclared scores,
- shuffled MAAT field nulls.

## Headline Results

Primary target: repeated-CV misclassification rate.

| Model | Mean Spearman | Mean AUROC |
|---|---:|---:|
| `external_geometry` | 0.3889 | 0.6685 |
| `combined_geometry` | 0.3824 | 0.6666 |
| `MAAT_supports` | 0.3241 | 0.6393 |
| `label_geometry` | 0.3107 | 0.6438 |
| `MAAT_v14_field` | 0.2795 | 0.6191 |
| `MAAT_defects` | 0.2434 | 0.5813 |

Scalar scores:

| Score | Mean Spearman | Mean AUROC |
|---|---:|---:|
| `label_disagreement` | 0.4299 | 0.6719 |
| `MAAT_robustness_loss` | 0.3301 | 0.6708 |
| `MAAT_scalar_cost` | 0.3226 | 0.6706 |

## Interpretation

This is a mixed but useful external result:

- MAAT scalar cost and robustness loss carry real positive signal on all three
  public datasets.
- The best overall predictors are simpler external geometry and local label
  disagreement baselines.
- MAAT v1.4 field features beat shuffled-null structure on breast cancer and
  digits, but not on wine.
- Therefore Paper 54 supports limited external signal, not external
  universality.
