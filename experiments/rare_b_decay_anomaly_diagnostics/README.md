# Rare B-Decay Structural Anomaly Diagnostics

This folder contains a synthetic toy benchmark for the extra phenomenological
note:

**Global Coherence versus Local Projection Defects**

*Rare B-Decay Anomaly Diagnostics in MAAT v1.6*

The script does not use LHCb, CMS, Belle, Belle II, or HEPData numerical
measurements.  It generates synthetic residual patterns to illustrate a
diagnostic distinction:

- coherent Wilson-coefficient-like residuals should appear as high-globality,
  low-locality modes;
- localized charm-like projection effects should appear as low-globality,
  high-locality modes.

Here "projection defect" means a charm-loop / charming-penguin-like
long-distance hadronic residual projected onto a small set of measured angular
observables and q² bins, not a new fundamental field.

Run:

```bash
python3 rare_b_decay_anomaly_diagnostics.py
```

Generated outputs are written to:

```text
outputs_phenomenological/
```

The script also runs a q²-bin shuffled null test. This preserves the same
synthetic residual amplitudes but disrupts bin coherence, testing whether the
diagnostic responds to structure rather than only residual size.

Key generated files:

- `toy_diagnostic_summary.csv`
- `toy_diagnostic_summary.json`
- `toy_residual_patterns.csv`
- `toy_bin_shuffled_null_samples.csv`
- `toy_bin_shuffled_null_summary.csv`
