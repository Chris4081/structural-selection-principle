# Paper 55 Experiment — CDCL Hardness Prediction on Standard SAT Families

**CDCL Hardness Prediction on Standard SAT Families**  
*A Benchmark for Graph-Local and Defect-Field Features*

This experiment is the first Paper-55 SAT benchmark that replaces the earlier
transparent DPLL target with real CDCL solver statistics from PySAT solvers.

The benchmark uses canonical SAT instance families generated locally:

- random 3-SAT,
- planted 3-SAT,
- modular/community 3-SAT,
- random 3-XOR encoded as CNF,
- graph coloring encodings,
- pigeonhole-principle encodings.

The instances are generated by deterministic code and solved with `Glucose3`
and `Minisat22` through `python-sat`. The target is a CDCL hardness proxy based
on solver conflicts, decisions, and propagations.

## Run

From the repository root:

```bash
python3 experiments/sat_cdcl_external_paper55/sat_cdcl_external_paper55.py
```

Outputs are written to:

```text
experiments/sat_cdcl_external_paper55/outputs_paper55/
```

## Scientific Status

This is a standard-family CDCL benchmark, not a SAT Competition benchmark.
No claim is made about industrial SAT, proof complexity, or `P != NP`.
The goal is narrower: test whether graph-local and multi-scale defect-field
features retain hardness signal against real CDCL statistics better than
scalar compression and shuffled-defect nulls. The decisive negative control is
leave-family-out transfer, where all feature sets fail to extrapolate cleanly.
